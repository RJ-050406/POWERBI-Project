 📊 Mobile Sales Dashboard – Power BI

This repository contains an interactive Mobile Sales Dashboard created using Power BI. The dashboard provides a complete overview of mobile phone sales, customer ratings, transactions,
and brand performance using a combination of KPIs, charts, maps, and slicers.

⭐ Dashboard Highlights

1. KPI Cards

Total Sales (769M)

Total Quantity Sold (19K)

Total Transactions (4K)

Average Sale per Transaction (40K)

These KPIs give a quick summary of overall sales performance. 

⭐ Visualizations Included

📍 Map – Total Sales by City

Displays sales distribution across multiple cities.

📅 Line Chart – Total Quantity by Month

Shows monthly quantity trends from January to December.

📊 Bar Charts

Total Sales by Mobile Model

Total Quantity by Mobile Brand 

📈 Stacked Bar – Customer Ratings

Displays customer satisfaction scores for different models.

🍩 Pie Chart – Transactions by Payment Method

Shows share of Debit Card, Credit Card, and Cash transactions.

📊 Bar Chart – Total Sales by Day Name

Helps understand which days generate maximum sales.

⭐ Filters (Slicers) Added
Brand
Mobile Model
Payment Method
Day Name

These slicers help users interact with the dashboard and view specific insights easily.
